# 裝備系統（一頁企劃，第一批）

> 狀態：企劃已確認（2026-11-25）。第二步「數字＋裝備店」已做成試作，網址加 `?gear=1` 才看得到（再加 `&coin=3000` 直接有 3000 山幣）；還沒有美術、還沒做組隊。所有數字只寫在 `js/data.js` 一個地方。

## 0. 三個原則

1. **預設裝備永遠不會壞**，最差就是「今天的速度」，不會卡死。
2. 裝備壞了**只會變慢或等一下**：不受傷、不掉東西、不會失敗。
3. 修理**便宜、按一下就好**。

## 1. 先要有錢：山幣（新東西，遊戲現在沒有錢幣）

| 怎麼賺 | 山幣 |
|---|---|
| 每走 1 公里（關著遊戲走的也算） | 10 |
| 登頂 | 30 × 難度（象山 30、玉山 150） |
| 每日任務每個／簽到 | 20／20 |

一般玩家一天大約 **150～200 山幣**。山幣只能買、修裝備，不能買寶物。

## 2. 裝備清單（五格＋冰爪）

耐久都是 100。「可用」是從全新用到 0 大約能撐多久。

| 欄位 | 裝備 | 效果 | 價格 | 可用 | 修滿 |
|---|---|---|---|---|---|
| 帽子 | 舊帽子（預設） | 無 | － | 不會壞 | － |
| | 毛帽 | 體溫掉得慢 15% | 300 | 60 公里 | 30 |
| | 防風保暖帽 | 體溫掉得慢 30% | 1200 | 120 公里 | 120 |
| 頭燈 | 舊頭燈（預設） | 每趟可走夜路 4 小時 | － | 不會壞 | － |
| | LED 頭燈 | 每趟夜路 8 小時 | 500 | 夜路 40 小時 | 50 |
| | 高亮度頭燈 | 整晚都能走 | 1800 | 夜路 80 小時 | 180 |
| 背包 | 舊背包（預設） | 無 | － | 不會壞 | － |
| | 輕量背包 | 體力掉得慢 10% | 400 | 60 公里 | 40 |
| | 透氣背架背包 | 體力掉得慢 20% | 1500 | 120 公里 | 150 |
| 雨衣 | （空的） | 雨天慢 15% | － | － | － |
| | 輕便雨衣 | 雨天不變慢 | 300 | 雨中 30 公里 | 30 |
| | 透氣雨衣 | 雨天不變慢＋雨天體溫掉得慢 20% | 1200 | 雨中 60 公里 | 120 |
| 登山杖 | 舊登山杖（預設） | 無 | － | 不會壞 | － |
| | 鋁合金登山杖 | 步速 +3% | 500 | 60 公里 | 50 |
| | 碳纖維登山杖 | 步速 +5% | 2000 | 120 公里 | 200 |
| （不佔格） | 冰爪 | 雪季 C+ 的山要有才能出發 | 800 | 雪地 30 公里 | 80 |

- **耐久怎麼掉**：照「有在發揮作用的里程」掉。帽子、背包、登山杖照走的公里；雨衣只在雨中掉；頭燈只在夜路掉；冰爪只在雪地掉。
- **掉到 0**：不會半路失效，**最後 1% 撐到這一趟結束**（登頂或下山），之後變「待修理」，自動換回預設裝備。
- **修理**：修滿 = 原價的 10%，缺多少算多少，按一下就好。**每天第一次修理半價**。半山腰的山屋也能修，價格 1.5 倍。
- **買錯**：隨時用半價賣回。
- **步速**一律經過 `SX.baseSpeed`（跟體能、好感加速同一個地方）。

## 3. 一個人爬：每種狀況怎麼算

| 狀況 | 規則 |
|---|---|
| 下雨沒雨衣 | 慢 15%，日記一句「雨有點大，走得慢了些」 |
| 晚上頭燈時數用完 | 走到前面最近的休息點紮營，天亮（05:00）自動繼續；紮營時體力體溫回滿 |
| 頭燈半路耐久歸 0 | 最後 1% 撐到這趟結束，之後待修理 |
| 雪季、C+ 的山、沒冰爪 | 不能出發（跟「雪季入山管制」同一個地方判斷，卡片寫原因） |
| 忘了修 | 大廳一個小紅點提醒，不發推播 |
| 沒錢 | 預設裝備照常走；每天第一次修理半價 |
| 新手 | 只有預設裝備；「新手禮物」連續 3 天簽到多送一件輕便雨衣 |
| 舊玩家 | 開放當天直接送輕便雨衣（不然雨天會比現在慢） |
| 關著遊戲 | 最多就是變慢或紮營等天亮，不會有別的損失；「離開時的日記」輕輕帶過 |

**出發前檢查**（新畫面，按「出發」後先看一眼）：天氣預報、會不會走到晚上、哪件裝備快壞了；可以直接修或照樣出發。

## 5. 組隊（最後做，單人確認後才動）

- **各走各的**：每個人照自己的裝備走。沒頭燈的人自己紮營，日記不怪任何人。
- **隊伍提醒**：出發前檢查多一行不寫名字的「隊上有 1 位山友的頭燈快沒電了」。
- **幫隊友修**：付錢幫修，兩人好友好感各 +2（每位好友每天一次）；對方看到「○○幫你修好了頭燈」。
- **隊伍裝備**（一個人帶、全隊受惠；因為各走各的，改成「人在同一座山上就有效，不用走在一起」）：
  - 帳篷（1000）：全隊夜裡紮營，早一小時（04:00）就出發。
  - 爐具（800）：全隊在休息點體力回得快 20%。

## 6. 美術（先規劃，不畫）

走路圖和爬階梯圖已定案不能動，裝備一律畫成**疊在登山客身上的獨立圖層**。

- 一件看得到的裝備要 4 張疊圖：平路走 8 格、爬階梯 16 格、累了走 8 格、彎道 16 格（共 48 格）。
- 要畫的：帽子 2、背包 2、登山杖 2 ＝ **6 件 × 4 張 ＝ 24 張**。
- 不用畫的：雨衣用現有的雨衣走路圖；頭燈用程式畫光暈；冰爪太小看不到。
- 商店小圖示：**13 張**（11 件裝備＋帳篷、爐具）。
- 想先省：第一批只畫帽子（8 張）＋圖示。

## 8. 試作時補上的三個小決定

- **裝備店入口**：先放在「背包」最上面（地圖和登山畫面都進得去）；有東西待修理時「背包」亮紅點。大廳的提醒等正式版再放。
- **在山上不能隨便換裝、修理**：正在爬山時要走到山屋才行（山屋修理貴 1.5 倍），不然「山屋可以修」就沒有意義。買東西隨時可以，但要下山或到山屋才換得上。
- **紮營的地方**：頭燈沒電後走到前面 500 公尺內最近的路標；沒有路標就在 500 公尺內的路邊。
