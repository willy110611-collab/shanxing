# 好友跟隨與好友好感度（2026-11-23 開發者定案）

這份是規格的唯一來源。數字在程式裡只寫一處（見各節「放在哪」），這裡是說明。

## 一、好友好感度

- 每一對好友一個共同的好感度（兩人看到同一個數字），存在伺服器。
- 刪除好友 → 好感度歸零（再加回來從 0 開始）。不會因為沒互動而下降。

### 怎麼增加（每天每位好友最多 +20，台灣日期換日）
| 事件 | 加多少 | 每天上限 |
| --- | --- | --- |
| 一起走（一起爬、跟隨同一段路，兩人都在走的距離） | 每 3 公里 +1 | +8 |
| 一起登頂（同一座山、同一隊） | +5 | 同一座山一天一次 |
| 按對方照片的愛心 | +1 | +3 |

### 等級與獎勵
| 等級 | 累計好感 | 獎勵 |
| --- | --- | --- |
| Lv1 | 0 | 剛成為好友 |
| Lv2 | 10 | 名字旁的愛心變粉紅 |
| Lv3 | 30 | 一起爬時，對方的寵物也跟著走 |
| Lv4 | 60 | 一起爬時速度 +1% |
| Lv5 | 100 | 登頂多一張兩人合照的拍立得 |
| Lv6 | 160 | 休息時坐在一起，有專屬聊天句子 |
| Lv7 | 240 | 一起爬時速度 +2% |
| Lv8 | 340 | 專屬稱號「生死之交」 |
| Lv9 | 470 | 一起爬時速度 +3% |
| Lv10 | 640 | 「一輩子的山友」：專屬徽章、登頂時兩人名字刻在山頂石頭上、體能上限 +0.01 |

- 加速只在跟那位好友一起爬（同隊）時有效；隊裡有多位好友取最高的一個，不疊加。
- 體能上限突破：每位 Lv10 好友 +0.01，最多 +0.05（2.000 → 2.050）。
- 畫面：好友名字旁 ♥ LvN；點開看「一起走了 X km、一起登頂 N 次」、下一級還差多少、各級獎勵。

## 二、好友跟隨（隊伍）

- 把現有「一起爬」升級成「隊伍」，不另做一套。
- 隊伍最多 6 人：隊長＋5 位隊員。隊長「邀請跟隨」，好友「接受」才加入；隊員隨時可「離開隊伍」，隊長可「解散」。
- 每個人照自己的體能速度走（好感度加速照上面規則）；先登頂的在山頂等，全員登頂才算這一座完成。
- 關掉遊戲也會跟著走（照現有離開時的補算），這就是代操。
- 全員登頂後，隊長收到通知「全隊登頂了，選下一座山吧」，隊長選好全隊一起出發。
- 能選的山：每位隊員自己能爬的山取交集（照權限最小的人）。不能選的山寫原因，例如「小明還沒解鎖」。
- 熱門山名額（玉山、嘉明湖、雪山）：隊長出發時幫全隊一次登記；名額不夠全隊用就不能出發。
- 隊長超過兩天（48 小時）沒上線：隊長自動交給最近上線的隊員，原隊長變隊員，回來時通知「某某接手當隊長了」。
- 跟隨登頂全部算數：登頂章、百岳紀錄、照片、體能（跟自己爬同樣規則：同一座山一天只算一次）。跟隨也算「有在走路」，會停止體能下降。
- 寶物：全隊這一趟撿到的寶物總數 = 每人平均數 × 人數，一件一件隨機分給隊員；用「隊伍代號＋山＋日期」當亂數種子，每支手機算出同一個結果，不用伺服器算。
- 隊員打開遊戲時，看一張「隊長帶你走了什麼」日記：爬了哪幾座、登頂章、照片、分到的寶物。

## 順序
1. 好感度（伺服器＋畫面）
2. 好友跟隨（之後一起走的公里數也算進好感度）

兩者都要更新資料庫並部署伺服器，部署前先問開發者。
