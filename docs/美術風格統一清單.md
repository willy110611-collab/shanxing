# 美術風格統一清單（2026-11-22 檢查）

這份清單是把 `art/` 裡約 288 張圖一張一張看過、再用手機尺寸（375×812）實際開遊戲看過之後整理的。
每一項都附「可以直接貼進 Gemini 的英文提示詞」。畫好的圖一樣放進 `art/raw/` 對應的資料夾，檔名照表格（id 不變），再跟 Claude 說一聲處理。

---

## 一、整體來說

**大部分圖的風格是一致的**：步道素材（樹、草、石頭、長椅、欄杆）、天空、地面、登頂插圖、大部分奇遇插圖，都是同一種「細深棕墨線＋柔和賽璐璐＋右上暖光」的手繪動畫風，放在一起不會打架。主角的服裝（卡其帽、紅黑格子襯衫、橄欖綠背包＋橘色睡墊）在每一張都有維持住，柴犬也大致一樣。

不一致的地方集中在幾個「家族」：**登山杖顏色、透明玻璃／細長物件吃到洋紅底、集印章混了三種畫法、表情與天氣小圖示、還有一批奇遇插圖跟文字對不上**。

### 最明顯的 5 個問題

1. **主角的登山杖變成粉紫色**：除了 `hiker_walk`（銀灰色，正確）以外，八格走路、爬階梯、累了走、轉彎走、雨天走、開心小跳，還有喘氣／喝水／看風景／擦汗／歡呼／鞠躬幾張，登山杖都是粉紅到紫色。在象山、阿里山、合歡山、玉山爬山畫面中一直看得到，是全遊戲最常出現的錯誤。
2. **奇遇插圖 e37～e48 跟文字對不上**：例如 `enc_e38` 文字是「五色鳥在樹洞口張望」，圖卻是草坡上的山莊和小水池；`enc_e39` 文字是「夢幻湖」，圖卻是阿里山紅色小火車。看起來是這一批畫的順序和檔名錯開了（詳見第三節）。
3. **寶物圖裡留著洋紅色**：`t_angel_tear_card`、`t_hiker_postcard` 上緣有一條亮洋紅色「膠帶」，`t_fog_note` 四周有洋紅色斑塊；`t_cloud_bottle`、`t_firefly_jar` 的玻璃變成粉紅色（透明玻璃透出了洋紅底）。
4. **玉山西峰還是「木造小廟」**：企劃已經把寺廟拿掉、改叫「路邊的小石龕」，但 `summit_yushan_west` 登頂插圖畫的還是有屋頂、木門的小神社；`t_sacredmother_stamp` 畫成紅色小教堂＋螢光綠草地，跟其他寶物章的畫法完全不同。
5. **雨天走路前後兩張不像同一件雨衣**：`hiker_rain_walk` 是亮檸檬黃、帽子在雨衣外面；`hiker_rain_walk8`（實際走路用的）是土黃色、大帽兜整個蓋住帽子，人也看起來像另一個人。

## 六、程式可以處理的（不用重畫）

這些是 Claude 改程式就能解決，不用請 Gemini 畫：

1. **細邊的粉紅殘邊**：很多去背圖邊緣還有一圈淡粉紅（例如 `t_front_sticker`、`t_whitebrow_card`、`t_cirque_card`、`t_crying_slope` 等卡片的邊、`pet_leopardcat_face` 的鬍鬚、`ui_bubble`、集印章紙張外緣、`grass_silver`／`grass_clumps`／`hedge_fern`／`frame_top` 的細葉）。這是 `js/art.js` 的去背（despill）只往內剝三圈、對細線條不夠力；可以加強細線條和白紙邊緣的處理。登山杖整根變紫的那幾張，因為顏色已經整個染進去，還是要重畫（第三節）。
2. **`face_happy`、`face_tired` 圖片底下有一條很淡的橫線殘留**：會讓自動裁切的範圍變大、頭像看起來偏小，程式裁切時可以忽略這種極細的殘線。
3. **玉山步道的地面有一塊塊亮暗不同的方形**：石板路和碎石路兩種地面貼圖接起來的地方看得出接縫（休息畫面最明顯），是程式貼地面的混合方式，不是圖的問題。
4. **合歡山步道上一顆扁平的橘色圓點**：出現在步道遠方，像是程式畫的標記，跟手繪畫面不搭，可以改用美術圖或拿掉。
5. **介面的框線粗細**：奇遇圖鑑卡片、背包空格、每日任務進度條是程式（CSS）畫的，用的是接近黑色的粗線；美術圖都是細的深棕線。改 CSS 顏色和粗細就能統一。每日任務的連續簽到圓點是淡紫色，也不在畫面色調裡，改 CSS 即可。
6. **稀有度小標（「稀有」藍色膠囊）是程式畫的**：顏色比 `rarity_rare` 框更亮，可以改成跟框一樣的霧面銀藍。
7. **底部工具列的「教學 ?」是程式畫的圓圈**：旁邊四個是手繪圖示，可以改用同風格的手繪小圖示（之後若要補，要請 Gemini 加畫一張 `icon_help`）。
8. **集印章大小不一**：`stamp_xiangshan` 在原圖裡比較小、`stamp_hh_shimen`／`stamp_xiangyang` 外面紙邊比較寬；程式裁切後顯示大小可以再統一（例如以紅圈為準縮放）。
