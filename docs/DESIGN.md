# 山行小日子（暫名）— 企劃書 v0.1

> 一款每天 3～10 分鐘、手作黏土微縮風的台灣登山療癒遊戲。
> 沒有懲罰、沒有每日任務壓力；放著會自己走，真的出門爬山還能加速。

## 1. 核心體驗
- **療癒**：圓潤溫暖的黏土微縮模型畫面、ASMR 腳步聲、雨天柔光、打瞌睡泡泡。
- **台味幽默**：Q 版三頭身人物背著瓦斯桶、半顆西瓜、電鍋、穿藍白拖、戴阿嬤斗笠爬山。
- **孤獨但被溫柔陪伴**：沿途讀到山友留下、會慢慢風化的匿名便條；可以替步道清泥、送愛心。

## 2. 主要畫面
1. **台灣大地圖（選山）**
   - 整座台灣做成一塊漂浮在雲海上的黏土小島，山脈有起伏、海邊有浪花縫線。
   - 每座可爬的山是一個「桌遊彩色木塊」地標，點了會彈起來，跳出路線卡：山名、海拔、路程、難度（以「幾顆飯糰」表示）、特色。
   - 已完成的山插上小旗子，並蓋上集印。
2. **登山畫面（主玩法）**
   - 2.5D 側視的步道微縮場景，移軸模糊營造「桌上模型」感。
   - 角色走在畫面中央，配合步頻做軟 Q 彈跳；寵物跟在後面。
   - 右上角是「漂浮黏土小島」雷達小地圖，路線用大地色縫線畫出，沿途地標以木塊立體彈出。
   - 沿途有疊石（帶笑臉塗鴉）、祈福樹、涼亭、山友便條、可撿的落葉和野花。
3. **山頂**：到達後蓋集印帳、拍山頂紀念照。
4. **我的小屋與相簿**：擺放收集到的拍立得、紀念品；換裝和選寵物。

## 3. 前進與體力（零壓力）
- **自動前進**：選好路線後角色自己走，關掉遊戲也照算（離線前進有上限，例如 8 小時）。
- **體力**：體力用完時角色頭上冒打瞌睡泡泡，自動坐下休息、慢慢回復；不會跳警告，也沒有懲罰。
- **真實步行加速（選用）**：在設定裡開啟定位後，現實走路的距離會換算成遊戲距離加成（例如 ×3）；只有網頁開著時才計算，並提醒用電量。
- **每 500 公尺**：解鎖一張「拍立得山景卡」，用手繪木框或拍立得外框包裝。第一版用手繪插畫卡，之後可以換成有授權的真實照片。

## 4. 天氣與時間
- 晴、多雲、霧、雨、夜晚會輪替（可對應現實時間）。
- 下雨時套上柔和濾鏡；角色會撐開大荷葉，或鑽進透著暖光的小帳篷紮營。
- 夜晚有星空和螢火蟲；高山清晨有雲海和日出（特別的拍立得）。

## 5. 角色、換裝與寵物
- **主角**：Q 版大頭人類，三頭身，可選髮型、膚色、衣服。
- **療癒配件**：橡子帽、葉子傘、松果背包、蘑菇帽、竹編登山杖。
- **台味惡搞負重**：瓦斯桶、半顆西瓜、藍白拖、阿嬤的斗笠、大同電鍋（外型原創、不放商標）、紅白塑膠袋、辦桌塑膠椅、珍奶。負重只影響外觀和趣味台詞，不影響速度，避免壓力。
- **寵物（跟在身邊）**：台灣黑熊、石虎、穿山甲、台灣藍鵲、山羌、帝雉、白鼻心、台灣獼猴等，在特定山區偶遇後可以帶著走，各有小動作。
- **分享**：「今日登山裝」一鍵產生截圖卡片，方便分享到社群。

## 7. 收集
- **集印帳**：每座山一個原創印章。
- **山腳小吃**：每座山腳一攤（例如烤香腸、愛玉、茶葉蛋、竹筒飯），吃了心情變好、體力回復較快。

## 8. 樹洞系社交（第一版：系統預寫）
- 地標處會有「山友便條」：系統預寫的碎碎念與取暖文（約 300 則，依山與天氣搭配），幾天後會「風化」換新。
- 玩家可以自己寫便條，先存在本機；之後接雲端時再開放給別人看。
- **替步道清泥**、**給便條愛心**時，噴出星星或音符粒子。
- 之後版本：接 Firebase 讓真人便條互通，並加上髒話過濾、檢舉與風化機制。

## 9. 聲音
- 步道材質 ASMR 腳步聲：碎石、落葉、木棧道、石階、泥土、雪地。
- 環境音：鳥叫、溪流、風、雨聲。
- 背景音樂：輕柔的木吉他、鋼琴、笛聲（Pixabay，下載前列清單確認）。

## 10. 技術
- 網頁遊戲（HTML／CSS／JS，單一 index.html ＋ audio 資料夾），手機直向（單手操作；電腦上置中顯示成手機比例）、禁止縮放、PWA 可加到主畫面、GitHub Pages 發布（新倉庫）。
- 黏土質感以 Canvas 向量繪製：圓角形狀＋柔和漸層＋邊緣高光＋手作壓痕雜訊＋縫線虛線＋移軸模糊；不用像素風。
- 定位加速用 Geolocation（使用者同意後才啟用）。
- 存檔在本機，提供存檔碼與 QR Code 搬家。

## 11. 製作順序
1. 引擎與台灣大地圖、第 1 座山（象山）可完整走完：前進、體力、天氣、拍立得。
2. 換裝與寵物、台味負重、分享卡。
3. 其餘 9 座山、集印帳、便條系統。
4. 真實步行加速、音效與音樂完整化、平衡調整。
